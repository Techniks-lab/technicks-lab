# TechnicksLab

TechnicksLab is a high-performance, responsive landing page built for a boutique IT & engineering services company. It showcases the company's offerings — custom software development, cloud infrastructure, cybersecurity, and AI/data engineering — through a bold, dark-themed single-page experience designed to convert visitors into clients.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Font:** Montserrat (Google Fonts)

## Sections

- Hero with stats
- About
- Services (Custom Software, Cloud & DevOps, Cybersecurity, AI & Data)
- Testimonials
- Pricing tiers (Starter / Growth / Enterprise)
- Contact form
- Footer

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Project Structure

```
src/app/
├── layout.tsx      # Root layout, fonts, metadata
├── page.tsx        # Landing page (all sections)
└── globals.css     # Tailwind config, theme colors
```
